# 💻 Acesso ao Projeto

Clone o repositório:

```bash
git clone https://github.com/claudiomacedo74/BookHub-python.git
```

Entre na pasta do projeto:

```bash
cd BookHub-python
```

Execute o projeto desejado utilizando Python.

Exemplo:

```bash
python nome_do_arquivo.py
```
