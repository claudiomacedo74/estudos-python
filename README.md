## 💻 Como executar

Clone o repositório:

```bash
git clone https://github.com/claudiomacedo74/estudos-python/blob/main/README.md
```

Entre na pasta:

```bash
cd estudos-python
```

Execute o projeto desejado:

```bash
python nome_do_arquivo.py
```
